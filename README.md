## Overview

**M3U8 & MP4 Video Link Detector** watches the network traffic generated by the webpage you are viewing and lists video and streaming URLs it detects.

It supports:

- `.m3u8` — HLS playlists
- `.mpd` — DASH manifests
- `.mp4` — direct video files
- `.webm` — WebM video files
- `.mov` — MOV video files

Detected links can be opened directly or sent to Coders Hub tools for playback or processing.

No account is required.

## Features

### Detect Video and Streaming URLs

Open a webpage, play or load its video, and click the extension icon to view detected media links.

The extension can find:

| Format | Type |
| --- | --- |
| `.m3u8` | HLS playlist |
| `.mpd` | DASH manifest |
| `.mp4` | Direct video file |
| `.webm` | WebM video |
| `.mov` | MOV video |

### Copy and Open Links

Detected URLs can be copied with one click or opened directly in your browser.

### Open in Coders Hub

Detected links can be sent to Coders Hub tools:

- **[M3U8 / HLS Downloader](https://coders-hub.com/tools/video/m3u8-hls-downloader)** — process supported HLS/DASH streams and convert them to MP4 in your browser.
- **[Online Media Player](https://coders-hub.com/tools/video/online-video-player)** — play supported HLS, DASH, and direct video URLs.

## How to Use

1. Open a webpage containing a video.
2. Play or load the video.
3. Click the **Coders Hub Video Link Detector** icon.
4. View the URLs detected from the page.
5. Copy a link, open it directly, or send it to a Coders Hub tool.

## Privacy

The extension is designed to keep captured URLs in your browser.

- Detected URLs remain in extension memory for the current tab.
- Captured URLs are cleared when the page reloads.
- Captured URLs are cleared when the tab closes.
- Detected URLs are not uploaded.
- The extension does not use analytics.
- No account is required.
- A detected URL leaves your browser only when you choose to open it in a Coders Hub player or downloader.

The extension does not maintain a server-side collection of detected URLs.

## Installation from Source

You can also run the extension from the source code.

### Chrome, Edge, Brave, Arc or Opera

1. Clone the repository:

```bash
git clone https://github.com/jmimohsin/M3U8-MP4-Video-Link-Detector-Extension.git
```

2. Open your browser's extensions page. For Chromium-based browsers, open:

```text
chrome://extensions
```

3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the cloned extension directory.
6. Open a webpage containing a video.
7. Play or load the video.
8. Click the **Coders Hub** extension icon to view detected links.

### Firefox

The extension is also available through [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/m3u8-mp4-video-link-detector/).

## Limitations

Some websites use DRM, authentication, encryption, or other protections that may prevent media URLs from being detected or accessed.

Detection of a URL does not provide permission to access, download, convert, or redistribute protected or copyrighted content.

## Responsible Use

Use the extension only with media you are authorized to access and use. Respect website terms of service, copyright, DRM, and applicable laws.
